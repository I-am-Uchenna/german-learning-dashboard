# 🇩🇪 Deutsch Lernen — A1 → B1 German Mastery

A comprehensive, interactive German learning platform designed for Goethe-Institut & TELC exam preparation, covering all six exam categories from A1 to B1.

## Features

### 📚 Complete Curriculum (A1 → B1)
- **Wortschatz (Vocabulary)** — 100+ words with flashcard system, spaced repetition tracking, and thematic grouping (Begrüßung, Arbeit, Wohnung, Bürokratie, Hamburg-specific terms)
- **Grammatik (Grammar)** — Full interactive lessons: Articles, Verb Conjugation, V2 Word Order, Cases (Nominativ → Genitiv), Perfekt, Nebensätze, Konjunktiv II, Passiv, and more
- **Lesen (Reading)** — Goethe/TELC format reading comprehension: notices, emails, articles, ads
- **Hören (Listening)** — Transcript-based listening exercises: announcements, phone calls, radio, interviews
- **Schreiben (Writing)** — Exam-format writing tasks: forms, emails, formal complaints, with sample answers and tips
- **Sprechen (Speaking)** — Prompt cards and structured speaking practice: introductions, requests, opinions, daily routines

### 🎯 Exam-Aligned
- Exercises modeled on real Goethe-Institut and TELC exam formats
- All 4 skills tested: Lesen, Hören, Schreiben, Sprechen
- Level-appropriate content for A1, A2, and B1
- Exam tips and strategies included

### 🗓️ Study Plan
- Structured week-by-week roadmap for each level
- Estimated hours and milestone targets
- Clear progression from A1 beginner to B1 intermediate

### 💬 Daily Life Phrases
- Essential phrases for: Bürgeramt, Doctor, Bank, Work, Shopping, Hamburg life
- Practical survival German for relocation

### 🎨 Design
- Dark editorial theme with warm amber accents
- Playfair Display + Outfit + JetBrains Mono typography
- Smooth animations and micro-interactions
- Fully responsive (desktop + mobile)
- Progress tracking with localStorage

## Tech Stack

- **React 18** with hooks
- **Vite** build tool
- **Pure CSS** (no framework dependencies)
- **GitHub Pages** deployment via Actions

## Getting Started

```bash
npm install
npm run dev
```

## Deploy

Push to `main` branch — GitHub Actions automatically builds and deploys to GitHub Pages.

Or manually:
```bash
npm run build
# dist/ folder contains the static site
```
